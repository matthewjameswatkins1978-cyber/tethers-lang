# Tethers Portable 0.2.0 release record

This release extends the frozen Portable 0.1.0 Rust façade with the generic
Workbench Guard protocol, conservative default policy, explain mode, policy
test runner, capability manifests, generic scopes, and thin subprocess
wrappers. It remains a local executable and never executes an action.

Base commit: `b62f8f3e31b319c13ce281e913f45f40640aad58`
Release tag: `tethers-portable-v0.2.0`

The original `tethers-portable-v0.1.0` tag, artifact, and checksum remain
immutable. New platform checksums belong in `SHA256SUMS` in the generated
release bundle.
