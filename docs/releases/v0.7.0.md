# Tethers 0.7.0

Status: released 2026-09-11
Language semantics: 0.1

Tethers 0.7 is the execution-boundary release. It makes the host's bounded
workspace, local Git, and direct process capabilities discoverable from the
CLI while keeping deterministic planning separate from policy and effects.

The Windows full-runtime layout is two executables: `tethers.exe` and the
sibling `tethers-engine.exe`. Host state is machine-local under the platform's
application-data directory; `.tethers/config.json` remains project-owned and
portable.

The runtime uses process supervision for provider lifecycle and cleanup. This
is not an OS security sandbox. Production Tethers is tested and audited with
OCaml/Rust suites; the separate Rocq tree is research and does not make the
production implementation formally verified or machine-extracted.

https://github.com/matthewjameswatkins1978-cyber/tethers-lang/releases/tag/tethers-v0.7.0.
