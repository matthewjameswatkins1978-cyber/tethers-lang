# Tethers 0.2.2

Status: Released
Tag: `v0.2.2`
Sign-off: accepted
Verified implementation checkpoint: `c6ea1e1652fa2785a1f06e0ace2fcd5e826ee6ec`

## What This Release Is

Tethers 0.2.2 is the Foundation-hardened, independently verified 0.2 runtime.
It adds no new major user-facing product capability. Foundation makes the
existing system more trustworthy, maintainable and reproducible through a
systematic programme of separately reviewed evidence packages.

## Highlights

- Operational correctness defects repaired across the codebase.
- Windows persistence and durability boundaries independently evidenced through
  the complete F3b/F3c/F3d/F3e sequence.
- Execution, outcome, and protocol ownership clarified — host controls what
  happens; Tethers plans what should happen next.
- OCaml module boundaries improved without changing Tethers 0.1 language
  semantics.
- Rust warning-producing dead surfaces removed or independently justified;
  15 dead-code items cleaned up.
- All-target Rust compiler warning gate enforced:
  `RUSTFLAGS="-D warnings"` on the canonical `just check` and `just verify`
  paths.
- Broader Clippy diagnostics remain advisory; F10 Clippy completed successfully
  with findings recorded for future consideration.
- Test-contract reconciliation completed across the test surface.
- Test execution performance measured and safe parallel Nextest validated.
- Operator and agent documentation reconciled across control documents, task
  templates, inactive integration guards, and closeout workflow.
- Final cold Windows clean-checkout Foundation proof passed: a pristine
  checkout reconstructed the complete system without relying on hidden local
  state.
- 1,592 Nextest tests passed, 2 skipped.
- Engine fixture checks: 29 PASS.
- MCP transcript cases: 15 PASS.
- Fixture validator: 46 JSON + 30 JSONL PASS.

## Supported Environment

- Native Windows
- PowerShell 7
- Rust 1.97.1
- OCaml 5.5.0
- Dune 3.24.0

Language semantics remain 0.1.

The active implementation directory remains `tethers-0.1/`.

## Known Limitations

- Source checkout release, not an installer or packaged distribution.
- No GUI or HQ.
- No automatic provider discovery.
- No remote transport, HTTP, OAuth, or multi-user service.
- No automatic retry or compensation.
- No Lantern Keeper integration yet.
- `--version` currently appears inside the strict CLI JSON usage envelope and
  exits 2, while correctly reporting product version 0.2.2.
- Does not claim zero Clippy advisories.

## Not Included

The explicitly deferred scope from the 0.2 release programme remains outside
this release: Lantern Keeper integration, safe retry or compensation,
additional providers and automatic discovery, remote transports and network
listeners, HQ, package management, marketplace, scheduling, adapters, and a
general plugin or AI-agent framework. Tethers 0.2.2 is not a general
programming language or an AI agent framework.
