# Tethers 0.2.0

Status: Released
Tag: `v0.2.0`
Sign-off: Complete
Published commit: `b5546411661dcbcb53e1cf2538eaec594c6f76f2`

## What This Release Is

Tethers 0.2.0 is the first usable standalone local Tethers runtime slice. It
connects:

```text
configured local provider
-> verified manifest admission
-> deterministic planning
-> explicit permission
-> intent-first serial execution
-> honest outcome
-> complete Trail
-> standard Result Anchor
-> bounded follow-up evaluation
```

## Highlights

- Deterministic Tether evaluation in the signed-off 0.1 language.
- Configured local stdio MCP providers.
- Verified manifests and exact provider, capability, and digest pins.
- `allow`, `ask`, `deny`, and `unavailable` policy outcomes.
- `succeeded`, `failed`, and `uncertain` execution outcomes.
- Intent recorded before an effectful call.
- No automatic retry.
- Exact one-shot approval.
- Durable replay protection across restart.
- Serial Result Anchor follow-up.
- Duplicate event rejection and causal depth eight.
- Public `check`, `run`, and `trail` commands.
- One real bounded file-move capability.
- Clean native Windows reconstruction and restart proof.

## Trust And Safety Properties

- Deterministic Conditions do not contain hidden AI judgement.
- Every effectful Action is explicitly permissioned.
- Uncertain effects are not guessed or automatically retried.
- Completed execution identities cannot repeat their effect after restart.
- Malformed, unavailable, stale, or out-of-scope inputs fail closed.
- Trails distinguish what was requested, permitted, attempted, and known.

## Supported Environment

- Native Windows.
- PowerShell 7.
- Rust 1.89.0.
- OCaml 5.5.0.
- Dune 3.24.0.
- Configured local stdio MCP providers.

This document does not imply support for macOS, Linux, remote transports, or
network services.

## Known Limitations

- Source checkout release, not an installer or packaged distribution.
- The active implementation directory remains `tethers-0.1/` because the local
  opam switch is path-bound.
- Language semantics remain version 0.1.
- No GUI or HQ.
- No automatic provider discovery.
- No remote transport, HTTP, OAuth, or multi-user service.
- No automatic retry or compensation.
- No Lantern Keeper integration yet.
- `--version` currently appears inside the strict CLI JSON usage envelope and
  exits 2, while correctly reporting product version 0.2.0.

## Not Included

The explicitly deferred scope from the 0.2 release programme remains outside
this release: Lantern Keeper integration, safe retry or compensation,
additional providers and automatic discovery, remote transports and network
listeners, HQ, package management, marketplace, scheduling, adapters, and a
general plugin or AI-agent framework. Tethers 0.2 is not a general programming
language or an AI agent framework.
