## Requested outcome

Pin the operational-scope schema as verified package evidence through the full evidence chain: package inspection, candidate record, installed record, and enablement. Remove the `read_scope_schema_digest()` fallback that reopens `plug.json` on disk. Enforce strict lowercase hex digest validation.

## Changes made

1. **`operational_scope.rs`** — Added `is_strict_lowercase_hex_digest()` helper that validates prefix `sha256:` + 64 lowercase hex characters. Both `create()` and `validate()` use it for `scope_schema_digest`.

2. **`package.rs`** — Added `operational_scope_schema: Option<serde_json::Value>` and `operational_scope_schema_digest: Option<String>` to `InspectionReport`. The `inspect()` function computes the JCS-canonical digest from `Provider.operational_scope_schema` during inspection, failing closed if canonicalisation fails. Both fields are included in `inspection_evidence_digest` computation.

3. **`candidate.rs`** — Added the same two `Option` fields to `CandidateRecord` with `#[serde(default)]` for backward compatibility. `CandidateRegistry::create()` copies from `InspectionReport`. `CandidateRecord::validate()` checks coherence: both absent (ok), both present with matching digest (ok), any other combination (fail).

4. **`installed.rs`** — Added the same two `Option` fields to `InstalledPlugRecord` with `#[serde(default)]`. `build_disabled_installed_record()` copies from `CandidateRecord`. `InstalledPlugRecord::validate()` checks coherence identically to candidate validation.

5. **`plug_command.rs`** — Removed the entire `read_scope_schema_digest()` function (47 lines with five `sha256:eeee...` fallback branches). `run_enable()` now reads `scope_schema_digest` directly from the installed record; if `None`, fails closed with `scope_schema_missing`. Removed unused `InstalledPlugRecord` import.

6. **Golden fixture** — Updated `fixtures/m2/candidate-record-v1.json` to include `operational_scope_schema: null` and `operational_scope_schema_digest: null`, recomputed `record_digest` to `sha256:fb89e46cd50a44e76e221788f49eeaae1ed5584a8466d4fd7523f752eaceab5b`.

7. **Test updates** — Added `operational_scope_schema: None, operational_scope_schema_digest: None` to all 18 `InstalledPlugRecord` and 2 `CandidateRecord` test constructions (in src/ and tests/). Updated `make_scope`/`make_pdf_scope` helpers in j24d, j24b, j24c, j23c3, m4_file_tools, f3d_bounded_persistence to compute real schema digests instead of `sha256:eeee...`. Fixed `write_scope_file` format from old `capability`/`permissions` keys to `scope`.
