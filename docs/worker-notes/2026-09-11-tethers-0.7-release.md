## Discoveries

GitHub main had advanced well beyond the original 0.7 branch, so direct
fast-forward publication would have omitted current 0.6 work. The release was
therefore integrated with a normal cherry-pick onto current main before PR
merge. GitHub reported no automated checks for the release branch; local
verification supplied the recorded acceptance evidence. A final full-suite run
also reproduced an existing timing-sensitive test-harness failure when the
global-state host-execution tests ran in parallel; the canonical `just verify`
gate now runs the full Rust suite with one test thread, and the complete suite
passes deterministically under that gate.

## Remaining risks

No known release blocker within packet scope. GitHub CI currently reports no
checks for this repository branch; future cross-platform assets remain outside
this verified Windows-only release.
