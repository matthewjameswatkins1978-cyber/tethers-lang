## Discoveries

- The host conformance suite checks only `inputSchema` against the manifest
  during discovery; the retained-session dispatch path (`stdio_provider.rs`)
  additionally verifies the advertised `outputSchema`. A provider that passes
  conformance can still be incomplete against the reviewed-manifest contract,
  which is what P5 surfaced.
- The manual is otherwise sufficient: the fresh author resolved MCP envelope
  details from the MCP 2025-11-25 protocol itself, which the manual names, not
  from hidden Tethers internals.
