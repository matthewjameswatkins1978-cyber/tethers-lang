## Requested Outcome

Implement `plug pack` to turn an author source directory into a deterministic
`.tetherplug`. Pack must reuse existing `package::inspect` as the validation
authority. Author declares meaning (paths, roles); Tethers generates evidence
(hashes, sizes, digest).

## Behavioural Result

### Public CLI

```
tethers-reference-host plug pack --source <ABSOLUTE_DIR> --output <ABSOLUTE_FILE.tetherplug>
```

- Both paths must be absolute
- Output must end in `.tetherplug`
- Existing output refused
- Source plug.json uses author-side `payloads` (path + role only)
- Packed plug.json contains generated `payload_index` (path + sha256 + size_bytes + role)
- Capabilities sorted by (name, version)
- Manifest digest generated when absent, verified when supplied
- Nested `.tetherplug` and `signatures/` refused
- Symlinks/junctions/reparse points refused
- Temp sibling file used; only renamed to output after `package::inspect` passes
- Source files unchanged on disk
- Byte-identical output across repeated packs

### Manifest digest behaviour

- If source manifest has top-level `digest`: verified via existing `manifest::verify_manifest`; stale/wrong digest refused
- If source manifest has no `digest`: calculated and inserted into packed manifest
- If author plug.json declares `manifest_digest`: verified against calculated value

## Discoveries

- `serde_json_canonicalizer` serializes with sorted keys, which makes the full

## Remaining Risks

- Windows reparse/junction detection uses only `is_reparse_or_symlink()` via
  `std::os::windows::fs::MetadataExt::file_attributes()`. The task authorises this
  approach, but it has not been independently fuzzed with exotic reparse tags.
- Manifest with digest uses `verify_manifest` (strict path); manifest without
  digest uses `canonicalize_and_digest` (generating path). Both paths reuse
  existing machinery. No third path exists.
- No direct test of junction-in-source-tree refusal in the pack path — existing
  `is_reparse_or_symlink()` should catch it but an explicit Windows test would
  strengthen the evidence.
