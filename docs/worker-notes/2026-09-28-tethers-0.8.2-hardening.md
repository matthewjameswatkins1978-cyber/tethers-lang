## Lane B — supervision, exec truth, git parser

Implementation (branch `fix/0.8.2-lane-b-supervision`):

- POSIX orphan-guard watchdog per supervised child: CLOEXEC death pipe, watchdog detached (setsid), header `pid pgid`, poll loop (EOF → liveness-probe → group SIGKILL; child-death → exit). Watchdog spawn failure FAILS the launch (no silent supervision downgrade). Survives host SIGKILL (kernel closes the write end on any termination). Residual PID-reuse race documented and bounded (liveness probe immediately before kill).
