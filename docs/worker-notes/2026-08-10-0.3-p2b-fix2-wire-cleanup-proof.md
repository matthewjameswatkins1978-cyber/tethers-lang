## Requested outcome

The original P2B-FIX implementation correctly enforced cleanup authority, but
the six focused unit tests exercised a `#[cfg(test)]` duplicate of the
production cleanup-result finalisation logic. Production contained identical
logic inline, so the tests proved the photocopy, not the machine.

This fix removes the duplicate by elevating `finalise_conform_result` to
ordinary private production code and calling it from `run_conform`. The tests
now exercise the exact same function that production uses.

## Changes made

- `src/plug_conform.rs`:
  - Removed `#[cfg(test)]` from `finalise_conform_result`, making it ordinary
    private production code.
  - Replaced the inline cleanup-result mapping in `run_conform` (lines 81-93
    of the base) with a direct call to `finalise_conform_result(result, scratch_cleanup_failed, workspace_cleanup_failed)`.
  - Six existing tests in `mod tests` continue to call `finalise_conform_result`
    without any change to their assertions.
  - rustfmt re-wrapped tuple returns to multi-line Debug style (cosmetic only).

- `docs/CURRENT_CLINE_TASK.md` — updated for FIX2.

- `docs/worker-notes/2026-08-10-0.3-p2b-fix2-wire-cleanup-proof.md` — new.

## Decisions and assumptions
