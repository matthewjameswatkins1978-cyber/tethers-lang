## Requested outcome

Prove that hostile providers cannot compromise host protocol correctness by
building a safe, deterministic adversarial protocol fixture (The Evil Bunny
Test) and showing Tethers refuses every protocol violation rather than
accepting false conformance. The packet required a Good Bunny control, twelve
hostile cases with observable public-journey evidence, smallest generic
production corrections only where the host was demonstrably fooled, regression
tests at the real conformance seam, and an honest experiment chronicle.

## Decisions and assumptions

- Fixture layout is implementation-owned: one provider binary with a
  `--mode` launch argument, one shared manifest, per-case pack descriptors so
  each case violates one primary contract and stays packable/inspectable.
- Operation `evil_probe` is deliberately non-`fixture*` so conformance
  exercises the pure discovery/shutdown boundary rather than the fixture-call
  helper path.
- EB-07 is split into EB-07a (mismatched `outputSchema`) and EB-07b (omitted
  `outputSchema`) because omission is the exact P5 manual gap.
- Updating the m3 fixture provider to advertise `outputSchema` is a stale-test
  fixture correction that the tightened discovery requires, not a semantic
  change.
- The shutdown case requires `graceful_exited` (the provider exits on stdin
  close); the Good Bunny, PDF, and m3 `valid` providers all do so within the
  bounded window, so requiring it does not regress conforming providers.
- Raw per-case public-journey evidence is committed because it is small
  (~60 KB) and is the durable "real plug pack / inspect / conform" proof.
