# Tethers Worker Notes

Each control-v1 task packet names one note in this directory before work starts.
Use a stable lower-case name:

```text
YYYY-MM-DD-short-task-name.md
```

Create the note from `docs/WORKER_NOTE_TEMPLATE.md`. Do not reuse a previous
task's note path. Accepted notes remain as concise project memory; the task
compiler selects only relevant notes for later packets.

These files record evidence-backed facts, not chat transcripts. Corrections
append a dated correction section or use a new note linked to the rejected
task; never silently rewrite accepted history.
