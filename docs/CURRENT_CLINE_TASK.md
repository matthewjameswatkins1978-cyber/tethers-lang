## Objective

After one evaluation finishes and creates a standard Result Anchor, place that
Anchor at the end of a host-owned FIFO queue. The host must then evaluate queued
Result Anchors one at a time, in stable first-in-first-out order, only after the
current evaluation has completely returned, without recursive stack execution,
without parallel evaluation, and without retrying a failed queue item.

A Result Anchor generated by a queued evaluation is appended to the tail. It
must not jump ahead of events already waiting.

## Required execution shape

```text
process initial external event completely
→ enqueue its standard Result Anchor, when one exists
→ return from that evaluation
→ dequeue the oldest Result Anchor
→ build one follow-up engine request
→ process it completely
→ append any newly generated Result Anchor to the queue tail
→ continue until the queue is empty
```

No recursive evaluator calls. Explicit outer draining loop only.
